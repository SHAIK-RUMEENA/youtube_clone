# YouTube Clone (React)

A modern YouTube-inspired video streaming frontend application built using React.js.  
The application demonstrates dynamic video rendering, component-based architecture, and responsive UI design similar to the YouTube platform.

---

## Live Demo

https://youtube-clone-1-6ufg.onrender.com
---

## Features
- Video playback interface
- Dynamic video pages using React Router
- Like and Subscribe functionality (UI simulation)
- Responsive layout similar to YouTube
- Component-based React architecture

---

## Tech Stack
- React.js
- JavaScript (ES6+)
- CSS
- React Router
- Render (Deployment)
